# OpenAgent Companion Book

Published static reader for the OpenAgent companion book.

- Website: <https://fengjikui.github.io/openagent-book/>
- Source project: private `fengjikui/openAgent` repository
- Contents: only chapters linked from `book/SUMMARY.md` and the reader assets required to render them

This repository is a generated publication artifact. Edit the Markdown in the source project, run
`uv run openagent-book-export --output-dir _site`, and then synchronize the managed `_site` output here.
